> **目标：** 打造一个 MBTI 测评网站，免费版引流（社交媒体传播），付费版提供深度解读报告，通过小红书等内容渠道获客。

## 二、双模式设计

### 免费版（引流款）— 分享解锁裂变机制

| 项目 | 内容 |
|------|------|
| 测评题目 | 28题精简版（4维度各7题） |
| 分享前 | 完成答题后展示「你的结果是 **I□□P** 类型」部分遮罩，制造期待 |
| 分享解锁 | 点击分享按钮 → 立即解锁基础结果（MBTI类型 + 一句话标签 + 200字概述） |
| 社交传播 | 自动生成带专属分享码的结果海报（带二维码），每个用户是推广节点 |
| 好友裂变 | 好友通过专属链接来测试 → 推荐人逐级解锁额外模块 |
| 引导付费 | 底部引导「完整5000字深度报告 ¥9.9 一次性解锁全部」 |

**裂变解锁阶梯：**

| 好友测试人数 | 解锁内容 |
|-------------|---------|
| 0（点击分享即解锁） | 基础结果：MBTI类型 + 200字概述 |
| 1人 | ❤️ 恋爱匹配指数 |
| 3人 | 💼 职场天赋图 |
| 5人 | 🔮 隐藏性格分析 |
| 任意时刻 | 💎 付费¥9.9直接解锁全部5000字报告（跳过裂变等待） |

**裂变追踪机制：**
- 每个用户生成专属 share_code
- 分享海报/链接携带 referrer_id
- 数据库记录 referral_count 和 unlocked_modules
- 好友测试后自动触发推荐人模块解锁

### 付费版（利润款）

| 项目 | 内容 |
|------|------|
| 测评题目 | 60题完整版（4维度各15题，含情境题） |
| 解读报告 | ~5000字深度分析，包含以下模块： |
| — 性格画像 | 核心特质、优势、盲区 |
| — 职业指南 | 适合的职业方向、工作风格 |
| — 恋爱关系 | 恋爱风格、最佳匹配类型、关系建议 |
| — 成长建议 | 个人发展路径、需突破的瓶颈 |
| — 社交风格 | 沟通方式、人际关系模式 |
| 输出格式 | 在线阅读 + PDF 下载 |
| 定价策略 | ¥9.9~¥29.9（后期可A/B测试） |
| 支付方式 | 微信支付 / 支付宝 |

### 数据库设计（Supabase）

```sql
-- 测评会话
CREATE TABLE sessions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  mode TEXT NOT NULL CHECK (mode IN ('free', 'paid')),
  answers JSONB NOT NULL,
  mbti_type TEXT NOT NULL,
  dimension_scores JSONB NOT NULL,
  referrer_id UUID REFERENCES sessions(id),    -- 推荐人ID
  share_code TEXT UNIQUE,                       -- 专属分享码
  unlocked_modules TEXT[] DEFAULT '{}',         -- 已解锁模块
  referral_count INTEGER DEFAULT 0,             -- 带来的好友数
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 支付订单
CREATE TABLE orders (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  session_id UUID REFERENCES sessions(id),
  amount INTEGER NOT NULL,          -- 金额（分）
  status TEXT DEFAULT 'pending' CHECK (status IN ('pending', 'paid', 'refunded')),
  payment_method TEXT,              -- 'wechat' / 'alipay'
  transaction_id TEXT,              -- 第三方支付流水号
  created_at TIMESTAMPTZ DEFAULT NOW(),
  paid_at TIMESTAMPTZ
);

-- 付费报告
CREATE TABLE reports (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  order_id UUID REFERENCES orders(id),
  session_id UUID REFERENCES sessions(id),
  report_content JSONB NOT NULL,    -- 各模块内容
  pdf_url TEXT,                     -- PDF 下载地址
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

## 五、AI 报告生成方案

### Prompt 模板

```
你是一位专业的 MBTI 性格分析师。根据以下测评数据，生成一份深度性格解读报告。

## 用户数据
- MBTI 类型：{type}
- 维度得分：E/I={ei}%, S/N={sn}%, T/F={tf}%, J/P={jp}%
- 关键答题模式：{key_patterns}

## 请生成以下模块：

### 1. 性格画像（800字）
描述这个类型的核心特质、内在驱动力、独特魅力。不要泛泛而谈，
要结合维度得分给出个性化的描述。如果某个维度得分接近中间，
要说明这种"中间状态"如何体现。

### 2. 职业指南（800字）
适合的职业方向、工作风格、团队角色、需要注意的职场陷阱。
给出3-5个具体职业推荐并说明原因。

### 3. 恋爱与关系（800字）
恋爱风格、在亲密关系中的表现、最佳匹配类型及原因、
关系中的潜在挑战和应对建议。

### 4. 个人成长（800字）
当前阶段的成长方向、需要突破的盲区、具体可执行的行动建议。

### 5. 社交风格（800字）
沟通方式、朋友圈特征、冲突处理模式、如何建立深度关系。

要求：
- 语气温暖但专业，像一位懂你的朋友
- 避免空洞的赞美，指出真实的盲区
- 结合维度得分给出差异化的分析
- 每个建议都要具体可操作
```

### 成本估算

- 每份报告约 4000-5000 字（中文）
- 使用 GPT-4o-mini / Claude Haiku 等低成本模型
- 单份报告成本约 ¥0.3~¥0.8
- 定价 ¥9.9 时毛利率 > 90%

## 六、小红书引流策略

### 内容模板

每条笔记围绕一种 MBTI 类型展开：

**标题公式：**
- 「{TYPE} 的人到底有多 {形容词}」
- 「测出 {TYPE} 后我整个人都释然了」
- 「{TYPE} 的致命弱点，99% 的人不知道」

**封面图：** 类型标签 + 吸引眼球的文案 + 小程序码/链接

**内容结构：**
1. 类型梗/共鸣点（吸引看完）
2. 几条精准的性格描述（建立信任感）
3. 引导测评 CTA（想知道你是什么类型？链接在评论区/主页）

### 发布节奏

- 每天发布 2-3 条
- 16 种类型轮换
- 同一类型可以多角度重复（职场/恋爱/社交/成长）
- 热点结合（如「ISTJ 看到前任结婚的反应」）
